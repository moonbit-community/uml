# Component examples

Each fixture exercises a distinct portion of PlantUML's component/description
grammar and can be rendered with `moon run . examples/component/<fixture>.uml`.

| Fixture | Coverage |
| - | - |
| `01-basic` | Bracket shorthand components and labelled dependencies |
| `02-interfaces` | Explicit components, aliases, provided interfaces, and lollipop links |
| `03-containers` | Package containment and cross-component relations |
| `04-metadata-and-notes` | Stereotypes, URLs, colours, databases, and multiline notes |
| `05-relationships` | Directed, dotted, and reversed component relations |
