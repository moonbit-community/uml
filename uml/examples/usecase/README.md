# Use case examples

Each `.uml` fixture is a focused, CLI-renderable example of supported
use-case syntax. `01-basic.svg` is the checked-in renderer output; regenerate
the remaining SVG files with the CLI when updating the example set.

| Fixture | Coverage |
| - | - |
| `01-basic` | Shape declarations, aliases, business actors/use cases, and include links |
| `02-include-extend` | Explicit aliases and extension dependencies |
| `03-packages` | Package scope and repeated shaped relation endpoints |
| `04-external-system` | `allowmixing` with a component external system |
| `05-business-metadata` | Business symbols, colors, URLs, stereotypes, and entity notes |
